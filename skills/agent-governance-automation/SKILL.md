# Agent Governance & Compliance Automation

自动化 AI Agent 治理、合规审查与行为审计框架。

## 功能

- **行为审计日志**：记录每个 Agent 的决策链路、工具调用、上下文长度
- **合规性检查**：敏感操作二次确认、权限边界、输出内容过滤
- **决策透明度报告**：生成可读的人类可理解的操作摘要
- **多 Agent 权限矩阵**：RBAC 风格的 Agent 能力分级控制
- **异常行为检测**：异常频率工具调用、越权操作、循环推理检测
- **合规报告导出**：PDF/Markdown 格式的治理报告

## 使用场景

- 企业级 AI Agent 部署的合规要求
- 多 Agent 协作场景下的权限隔离
- 对 AI 决策有审计要求的金融/医疗场景
- 防止 Agent 被滥用或 Prompt 注入攻击

## 核心指标

- 决策可追溯率
- 合规检查通过率
- 审计报告生成耗时
